# Dvlce plugins

Free audio plugins by DVLCE: compressors, EQ, limiter, vocal tools, saturation, delay, reverb and more.
Windows (VST3 + Standalone) and macOS (AU + VST3 + Standalone, universal).

This repository holds the release downloads only. Browse them at **https://plugins.dvlce.ca**.
